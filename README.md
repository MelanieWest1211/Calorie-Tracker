# Calorie-Tracker-
A repository of a calorie tracker app I made as part of my mobile app development coursework

--FEATURES-- 
- Current features include a meal logging system for different days
- A side-swiping feature which allows users to see and modify their logs for past days
- A table of calorie information which allows users to see their calorie intakes over longer periods of time
- Toggleable reminder notifications which can be used to remind users to log breakfast, lunch and dinner
- Firebase cloud storage, allowing users to log meal types that other users have submitted
- Calorie sharing information via Android Sharesheet, allowing users to share information about the food they have eaten over an individual day and across multiple weeks

--FEATURES IN DEVELOPMENT--
- More detailed nutritional information; this would give users the option to submit information such as protein or carbohydrates as well as raw calorie information. This has been completed, however I haven't updated the repository to include it yet
- A barcode scanning feature, allowing users to log nutritional information about different meals by scanning barcodes on packages. This feature is currently under development

--KNOWN ISSUES--
- Currently working on fixing a bug which causes the total calories to fail to sync properly when editing an existing meal
- Fixing some graphical issues which occur when rotating a device

--FUTURE FEATURES-- 
- Optional cloud storage for individual users, allowing users to access their meal histories across different devices
- Custom notification creation, allowing users to create custom notifications at different times according to their meal needs
- More meal trend infographics, such as line charts in order to provide more visualisation options for users to view their meal trends over time
- Individual recipes, where users can create custom recipes made up of multiple different ingredient types, making it easier to change meal information for meals comprising multiple ingredients

--GETTING STARTED--
- In order to install and use the app, simply download the APK file provided
- The source code for this project is provided in the source code folder
- Please note, this app is only compatible for android devices running android 12 or above
